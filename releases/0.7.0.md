## What's Changed

### Fixed: `json_safe` infinite recursion on self-referencing object graphs

The `json_safe` ([`helpers.py`](https://github.com/mayty/claude-agent-wrap/blob/0.7.0/agent_wrap/providers/litellm_common/helpers.py)) recursive serializer could recurse infinitely when it encountered a self-referencing data structure (e.g. a dict containing itself, or a cycle through nested containers). The function now detects cycles and breaks them cleanly instead of looping forever.

**Full Changelog**: https://github.com/mayty/claude-agent-wrap/compare/0.6.0...0.7.0
