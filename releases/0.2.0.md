## What's Changed
### Added: auto-update check

`agent` and `rebuild_agent` now perform a best-effort `git fetch` against the wrap-dir's tracking branch on each invocation. If `HEAD` is behind, you're prompted to pull; on accept, the wrapper runs `agent-wrap_update`, re-sources [`agent-wrap.bashrc`](https://github.com/mayty/claude-agent-wrap/blob/0.2.0/agent-wrap.bashrc) in the parent shell, and exits without launching/rebuilding (re-run your original command afterward). Any error path (no network, detached HEAD, non-git wrap-dir, fetch timeout) silently skips the check so a flaky network never blocks a launch. Set `CLAUDE_AGENT_SKIP_UPDATE_CHECK=1` to disable entirely.

### Added: `agent --base` flag

Launch the base `claude-agent` image and bypass the current directory's `Dockerfile.agent` for a single invocation — useful for working around a broken or stale project image. Project-specific `EXPOSE`, `agent-user`, and `agent-run-args` directives are skipped. The flag is consumed by `agent` itself; remaining args are forwarded to the in-container `claude` CLI.

**Full Changelog**: https://github.com/mayty/claude-agent-wrap/compare/0.1.0...0.2.0
