## What's Changed

### Breaking: Docker Engine 25.0 or newer is now required

The agent container now joins the wrapper's sidecar network in addition to the network the project declares. `agent run` reads the daemon version and stops when it is older, and names the version it found. `agent rebuild` is not gated.

A version the wrapper cannot read is not treated as too old. An unreachable daemon reports the error it always did. See [Requirements](https://github.com/mayty/claude-agent-wrap/blob/0.12.0/docs/getting-started.md#requirements).

### Added: `agent secrets check` reports every sidecar when you name none

`agent secrets check` needed a sidecar name before. A check of the whole host therefore took one run per sidecar. The name is now optional. Without it, one table lists the secrets of every sidecar the wrapper knows about, in sidecar-name order.

A sidecar that requires no secrets gets no rows, and one line under the table names it. `agent secrets check` totals the missing secrets on stderr under the table. That line names the sidecars they belong to. Any missing secret sets the exit code to `1`.

### Changed: `agent secrets` finds a repeated paste, describes each secret, and gives each table a sidecar column

The wrapper used to store a secret that you pasted twice as-is. The sidecar started, and the provider rejected the doubled credential later. `agent secrets set` now examines each entered value. When the value is several copies of one shorter string, the prompt says how many copies it found. It gives the length of that value and the length of one copy. Answer `y` to store the single copy.

Any other answer keeps the value exactly as you typed it. The prompt on the first `agent run` applies the same guard. `agent secrets check` now reports the length and a masked hint for each present secret, such as `sk***ef`. The command never prints the value. A secret that cannot be hinted at safely reads `***`.

`agent secrets check` now prints one table. The table gives a column to the sidecar, the key, the state, the length and the hint. The key column no longer repeats the sidecar name. A missing secret leaves the length cell and the hint cell empty.

`agent secrets clear` and `agent secrets cleanup` now print the keys they remove as a table. That table gives a column to the sidecar, the key and the state. `agent secrets cleanup` removes the keys that no known sidecar claims, so one of the removed keys can carry no sidecar name. That key reads `<none>` in the sidecar column. Each table fits its columns to the content, and carries no colour in a pipe. See [`agent secrets`](https://github.com/mayty/claude-agent-wrap/blob/0.12.0/docs/shell-commands.md#agent-secrets).

### Fixed: a startup script can now create the network the project declares

A project can pair `# agent-run-args: --network myproj-net` with a `startup.sh` that creates the network. Such a launch used to fail when the network did not exist yet. It stopped with `network 'myproj-net' (from agent-run-args) does not exist`. The script that would have created it never ran. The launch no longer needs the project's network to exist beforehand, so the script runs and creates it. See [Startup script](https://github.com/mayty/claude-agent-wrap/blob/0.12.0/docs/docker-sandboxing.md#startup-script).

### Fixed: a shared sidecar no longer holds a project's network open

`agent run` used to connect a sidecar to the network the project declares, and never disconnected it. A sidecar is shared by every project on that provider. It outlives one run, so the connection stayed until the last agent on that provider exited. `docker compose down` reported `network has active endpoints` in the meantime.

The wrapper no longer attaches a sidecar to the project's network. `docker compose down` now succeeds as soon as the agent exits.

### Fixed: the auto mode notice no longer appears on the DashScope and DeepSeek providers

Auto mode on the `litellm-dashscope` and `litellm-deepseek` providers showed a notice about classifier request charges. The notice held the first checked action until you pressed Enter. Acknowledging it held the notice off for 24 hours at most. The wrapper now sets `CLAUDE_CODE_AUTO_MODE_SERVER=0` for both providers. Auto mode then always uses its own classifier requests, and the notice does not appear. The other providers still show the notice.
