## What's Changed
### Breaking: shell function renames

The wrapper now exposes a single `agent` command with subcommands, which supports tab completion in bash. **Old functions no longer exist** after re-sourcing `agent-wrap.bashrc`:

| Old | New |
|-----|-----|
| `agent` | `agent run` |
| `rebuild_agent` | `agent rebuild` |
| `create_custom_agent` | `agent create` |
| `agent-wrap_update` | `agent update` |
| `agent_usage` | `agent stats` |

### Changed: better project isolation

A new `.claude/image-cache/` directory is now created and mounted on `agent run`. Existing projects get it automatically on the next launch.

### Changed: providers plugin system

The bash `source providers/<name>/provider.sh` mechanism is replaced with a Python ABC (`agent_wrap/providers/base.py`). Each provider is now a subdirectory with `provider.py`; `agent-wrap.bashrc` no longer sources shell scripts. Auto-discovery in `agent_wrap/providers/__init__.py` scans `*/provider.py` for concrete `Provider` subclasses at runtime. To add a custom provider, drop in `agent_wrap/providers/<name>/provider.py` (subclass `Provider` or `LiteLLMProvider`) and set `AGENT_PROVIDER=<name>`.

### Added: Dashscope provider

Route model traffic through Alibaba Cloud DashScope instead of AWS Bedrock. Set `AGENT_PROVIDER=litellm-dashscope` and add a `DashScopeAPIKey` to `~/claude_keys.json`. See [README.md](https://github.com/mayty/claude-agent-wrap/blob/0.4.0/agent_wrap/providers/litellm_dashscope/README.md).

### Improved: `agent update`

More robust handling of non-fast-forward situations, detached HEAD, and `default-CLAUDE.md` propagation conflicts.

Further updates mostly won't require `agent-wrap.bashrc` resourcing.

### Other: total python rewrite

`agent-wrap.bashrc` shrank from ~590 lines to ~80: it now defines a single `agent()` function that delegates to `python3 -m agent_wrap`. All orchestration logic lives in the new `agent_wrap/` Python package (`commands/`, `providers/`, `config.py`, `lib/`). Also included: `pyproject.toml` with a full dev toolchain (ruff, pyrefly, pytest), a `Makefile` (`make check` runs lint + format-check + typecheck + tests), a GitHub Actions `check.yml` workflow, and a comprehensive test suite covering all commands and providers.

### Other: `ops/` directory reorganization

`Dockerfile`, `default-CLAUDE.md`, `md_to_html.js`, `statusline.py`, `telegram-notify.sh`, `validate-dockerfile-agent`, and `wl-paste-shim` moved from the repo root into `ops/`. If you reference these files by path in scripts or tooling outside the wrapper, update those paths accordingly.
