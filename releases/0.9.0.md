## What's Changed

### Added: `litellm-anthropic-sub` provider for Anthropic Team Premium subscriptions

A new [`litellm-anthropic-sub`](https://github.com/mayty/claude-agent-wrap/blob/0.9.0/agent_wrap/domain/providers/litellm_anthropic_sub/provider.py)
provider routes Claude Code through Anthropic's own API,
`https://api.anthropic.com`, via its own LiteLLM sidecar — but, unlike every other
built-in provider, to spend an **Anthropic Team Premium subscription seat** rather than
per-token API credits. It declares no secret: `agent secrets check litellm-anthropic-sub`
reports it needs none, so `agent secrets set` never prompts for it. Instead, authenticate
once per machine with a one-time in-container `/login`; the resulting claude.ai
credential persists across every project and every `agent run` afterward. `agent stats`
reports a truthful `$0.00` for its rows, since a subscription seat has no marginal
per-token cost — track actual consumption via `/usage` in Claude Code or the Team seat
usage view on claude.ai instead. Select it with `AGENT_PROVIDER=litellm-anthropic-sub agent
run`; see [docs/providers.md](https://github.com/mayty/claude-agent-wrap/blob/0.9.0/docs/providers.md)
and the provider's own [README](https://github.com/mayty/claude-agent-wrap/blob/0.9.0/agent_wrap/domain/providers/litellm_anthropic_sub/README.md)
for credential setup and gateway-mode side effects (Remote Control, fast-mode checks,
and MCP tool search behave differently under a custom `ANTHROPIC_BASE_URL`).
