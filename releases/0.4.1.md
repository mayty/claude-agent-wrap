## What's Changed
### Fixed: pull LiteLLM sidecar image if missing

The LiteLLM sidecar image is now pulled automatically on first run when it isn't present locally. Previously the sidecar would fail to start if the pinned upstream image was missing; the wrapper now detects that, streams `docker pull` progress (with a "first run, may take a few minutes" notice), and aborts loudly if the pull fails.

**Full Changelog**: https://github.com/mayty/claude-agent-wrap/compare/0.4.0...0.4.1
