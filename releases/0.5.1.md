## What's Changed
### Changed: `agent stats` LAST LAUNCH column is now date-only

The LAST LAUNCH column in [`agent stats`](https://github.com/mayty/claude-agent-wrap/blob/0.5.1/agent_wrap/commands/stats.py) previously showed each project's most recent launch as a date and time (`2026-06-10 11:21`); it now shows the date alone (`2026-06-10`), trimming noise from the table.

### Improved: WSLg clipboard mount no longer exposes the host filesystem

On WSL2 hosts the wrapper bind-mounted all of `/mnt/wslg` to enable clipboard passthrough, but on WSLg that tree includes `/mnt/wslg/distro` — the host distro's entire root filesystem. Because the container runs with the host user's UID, this left the whole host home (SSH config, `~/.kube`, shell history, and so on) readable from inside the sandbox. [`agent run`](https://github.com/mayty/claude-agent-wrap/blob/0.5.1/agent_wrap/commands/run.py) now mounts only the two sub-paths the feature actually needs — `/mnt/wslg/.X11-unix` and `/mnt/wslg/runtime-dir` (the Wayland socket) — so `Ctrl+V` image paste keeps working while the host filesystem is no longer visible. See [docs/wslg-clipboard.md](https://github.com/mayty/claude-agent-wrap/blob/0.5.1/docs/wslg-clipboard.md).

### Fixed: `agent stats` showed `?` instead of `$0.00` for error-only projects

A project whose every request errored out was never billed, leaving a genuine zero cost — but [`agent stats`](https://github.com/mayty/claude-agent-wrap/blob/0.5.1/agent_wrap/commands/stats.py) inferred "unknown pricing" from a zero total and rendered it as `?`, conflating a known zero with a missing price. Cost buckets now track an explicit unknown-pricing flag, set only when a billable request has no known price, so error-only projects correctly show `$0.00` while genuinely unpriced requests still show `?`.

### Other: changelog and per-version release notes

The repo now ships a [CHANGELOG.md](https://github.com/mayty/claude-agent-wrap/blob/0.5.1/CHANGELOG.md) index linking to full, per-version release notes under [`releases/`](https://github.com/mayty/claude-agent-wrap/tree/0.5.1/releases), backfilled for every release from 0.1.0 onward. A [release notes style guide](https://github.com/mayty/claude-agent-wrap/blob/0.5.1/releases/styleguide.md) defines the house style new notes should follow, and the [README.md](https://github.com/mayty/claude-agent-wrap/blob/0.5.1/README.md) navigation table now points at the changelog.
